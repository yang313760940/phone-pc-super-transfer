# 手机语音转写 · 分享给同事使用说明

一套「手机录一段中文 → 电脑本地转写成文字」的极简工具。**每人在自己电脑上装一套，各用各的**（不是共用一台服务器）。

- **手机端**：一个 App（`VoiceSend`），录音并发送。
- **电脑端**：一个 Python 服务，接收音频、本机 CPU 转写、把文字显示回手机 + 写进电脑剪贴板/文件。
- 全程本机转写，不上传第三方。

> App 采用「首次连接信任」证书方案：**一份 APK 通用**，谁的电脑都能连，不用为每人重打包。

---

## 一、你需要准备

1. 一台 **Windows 10/11** 电脑，装好 **Python 3.10+**（安装时勾选 “Add Python to PATH”）。
2. 一个 **安卓手机**。
3. 手机和电脑连在**同一个 Wi-Fi / 局域网**。

---

## 二、电脑端安装（一次性，约 5–10 分钟 + 首次下载模型）

拿到分享包（含 `server/`、`app/…apk`、本说明）后：

1. 在本仓库根目录，右键 PowerShell 运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File server\setup_for_colleague.ps1
   ```
   它会自动：装依赖 → 按你电脑当前 IP 生成本机证书 → 提示放行防火墙 8443。
   （第一次会下载中文模型约 1GB，耐心等一次。）

2. 启动服务：
   ```powershell
   python server\run_https.py
   ```
   记下它打印的地址，形如 `https://192.168.x.x:8443`。

3. 若真机连不上，多半是防火墙：以**管理员**再跑一次 `server\allow_firewall.ps1`（放行 TCP 8443 入站）。

> 电脑重启/换 Wi-Fi 后：若 IP 变了，重跑 `server\reissue_for_ip.ps1`（重生成证书 + 重启服务），**App 无需重装**。

---

## 三、手机端安装

1. 把 `app\app\build\outputs\apk\debug\app-debug.apk` 传到手机（微信文件传输/数据线/网盘均可）。
2. 手机上点开安装。若提示「未知来源」，允许一次。
   - 小米/红米：设置 → 开发者选项 → 打开「USB 安装」后，或直接允许「安装未知应用」。
3. 打开 App「VoiceSend」：
   - 在**服务器地址**框填电脑上一步的地址，如 `192.168.0.153:8443`（不用带 https，App 会自动补全）。
   - 点「开始录音」→ 说一段中文 → 再点「停止并发送」。
   - 稍等 → 显示转写文字，可点「复制」。手机与电脑上都有文字（电脑写进剪贴板 + `server/latest.txt`、`history.txt`）。
   - **首次连接**会自动信任你这台电脑的证书；以后不用再管。

---

## 四、常见问题

- **连不上 / 一直失败**：① 手机和电脑是否同一 Wi-Fi；② 电脑服务是否在运行；③ 防火墙是否放行 8443；④ 地址 IP 是否和电脑当前 IP 一致。
- **提示「服务器证书已变化」**：你换了电脑或证书重生成过。到手机系统设置 → 应用 → VoiceSend → 清除数据，重连即可（会重新信任）。
- **电脑上没看到文字**：看 `server\latest.txt`（最新一条）与 `server\history.txt`（历史）；也直接 Ctrl+V，最新一条已进剪贴板。
- **转写慢**：首次要加载模型，之后正常；一段几秒语音通常 1–2 秒出字。

---

## 五、隐私与范围

- 语音只在你自己的电脑本机转写，**不上传任何第三方**。
- 自用、单用户、逐段录音；不带账户/历史云同步/实时流式。
- 证书是自签 + 首次信任（TOFU），仅适合**可信局域网**内自用，不要暴露到公网。
