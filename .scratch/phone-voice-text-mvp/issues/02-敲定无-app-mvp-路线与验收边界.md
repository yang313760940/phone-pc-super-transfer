# 02: 敲定无 App MVP 路线与验收边界

Type: grilling

Blocked by: 01
Status: resolved
## Question

在用户已经指定“局域网 H5 页面内录音发送，不开发原生安卓 APK”的前提下，是否接受首次手机 HTTPS 信任设置，并由电脑本地完成中文语音转写？随后确认足以开工的最小验收边界。

## 已确认边界

- 手机入口：局域网 H5 页面内录音、发送；不重新追问 H5 还是 APK，也不把系统录音后网页选文件上传当作默认路线。
- 个人自用、逐段中文语音转写，电脑显示可复制文字；先暂放跨语言翻译和边说边出字。
- 本轮先规划后实施，不提前编码或安装环境。

## 待用户确认

- 网页麦克风需要安全上下文这一事实已经查清：普通电脑私网 IP 的 HTTP 页面缺少相应前提。局域网 H5 直接录音候选采用手机认可的 HTTPS；只询问用户是否接受首次证书信任设置，不让用户替代理调查技术事实。
- 识别位置：推荐先用电脑本地 CPU int8 中文转写，首次准备模型后不向第三方转写 API 上传语音；是否接受这一取舍由用户确认。

## 建议最小验收

手机打开局域网 H5 页、授予麦克风权限、录制一段中文语音，停止后发送；电脑收到完整音频后自动转写，并显示可复制文字。只保留录音、发送/识别状态和失败后的手动重试，不加用户系统、数据库、历史管理或实时流式能力。

真实手机录音格式、证书信任和实际等待时间属于此路线的最小验证项；不承诺未测的延迟，也不扩成兼容性工程。此票通过现场问答记录最终路线与验收结论。
