# 04: 证书与局域网监听，接通端到端闭环

**What to build:** 

**Blocked by:** #01, #02, #03

**Status:** ready-for-agent

## 目的

把前三张票拼成一条真机可用的闭环：手机经局域网 HTTPS 打开页、录音发送、电脑本机转写、页面显示可复制文字、失败可重试。本票处理证书、监听与端到端联通，是收口票。

## 范围

- 为访问地址生成自签证书（证书需与手机实际访问的主机名/IP 相符），服务以 HTTPS 监听局域网地址与端口。
- 把 `POST /upload` 接到 `asr.py`：落盘文件 → 转写 → 按契约返回 `ok/text/duration_ms`；解码失败填 `stage=decode`、识别失败填 `stage=asr`、其它填 `internal`。
- Windows 防火墙放行该端口入站局域网流量；记录监听地址与访问 URL。
- 手机首次访问接受证书例外，之后直连。

## 验收

1. 真机打开 `https://电脑局域网IP:端口/` 加载成功，录一段中文，电脑转写，页面显示可复制文字——规格验收第 1-3 条同时成立。
2. 构造一次转写失败仍能在页面看到 `error` 并重试成功——第 4 条成立。
3. 断网抓包或日志确认无第三方转写请求，音频不出本机——第 5 条成立。
4. 记录真实手机录音 `mimeType`、证书信任步骤、一段典型语音的端到端耗时。

## 不做什么

不加鉴权、不加多用户、不部署公网、不做异地访问。
