# 01: 接收页与上传接口

**What to build:** 

**Blocked by:** None (can start immediately)

**Status:** resolved

## 目的

按规格搭出电脑端最小服务：手机能打开录音页、把一段音频完整传上来。本票只做接收，不接转写。

## 范围

- 单进程 HTTP 服务，监听局域网地址；`GET /` 返回录音页静态文件。
- `POST /upload`：multipart 单文件字段 `audio`，落盘到临时目录，校验字节数与上传一致；单段上限 25 MB，超限返回 `{"ok":false,"error":"...","stage":"internal"}` 与 4xx。
- 先返回占位文本（如 `{"ok":true,"text":"","duration_ms":0}`），让页面闭环可先跑通；接真实转写由后续票替换。
- 可选字段 `filename` 只写日志，不参与解析。
- 错误一律回可读 JSON，不把栈丢给页面。

## 验收

1. 电脑本机 `GET /` 能拿到页面文件。
2. `curl` 上传一段测试音频，服务端落盘文件字节数与请求一致。
3. 超过 25 MB 得 4xx 与可读 `error`，不产生半截文件残留。

## 不做什么

不写录音页 UI、不接 ASR、不配证书（分别属其它票）。
