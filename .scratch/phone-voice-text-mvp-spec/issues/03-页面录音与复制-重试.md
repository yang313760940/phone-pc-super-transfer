# 03: 页面录音与复制/重试

**What to build:** 

**Blocked by:** #01

**Status:** resolved

## 目的

手机 H5 页里录一段中文语音、发送、看到转写文字并复制；失败能重试。页面只面向这一条闭环。

## 范围

- `getUserMedia({audio:true})` + `MediaRecorder` 录一段，停录后把 Blob 以 multipart 字段 `audio` 发到 `POST /upload`；优先 `audio/webm;codecs=opus`，不支持时退回浏览器默认并记录实际 `mimeType`。
- 结果区显示 `text`，提供「复制」按钮写入剪贴板。
- 失败时显示 `error` 与「重试」，重试复用内存里的同一段 Blob 再发，不要求重录。
- 只保留：录音按钮、发送/识别状态、结果与复制、错误与重试。不加历史列表、参数面板、流式。

## 验收

1. 授权后可录可停，发送后界面进入等待态。
2. 后端返回 `ok=true` 时显示文字，「复制」能把整段放进剪贴板。
3. 后端返回 `ok=false` 或断网时显示 `error` 与「重试」，点重试重发同一 Blob 成功。
4. 页面对接口只是普通同源 `fetch`，无第三方脚本。

## 不做什么

不做多段队列、不做音频编辑、不做离线缓存。
